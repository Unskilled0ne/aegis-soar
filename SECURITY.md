# Security Policy

## Educational & Operational Notice
Aegis-SOAR contains automated incident response playbooks that can execute network-level containment actions (such as `iptables` drop rules) when executed in live environments. Always verify simulation mode flags (`--simulate`) during testing to prevent accidental disruption to production network traffic.

## Reporting Vulnerabilities
If you identify security bugs or bypasses in the SOAR sanitization layers:
- **Do not** file public GitHub issues.
- Disclose responsibly to: **btsiamouras@gmail.com** or via [LinkedIn](https://www.linkedin.com/in/vasilis-tsiamouras/).
